# Security

Report a vulnerability privately through GitHub: https://github.com/cenksimsek1988/cenk-overtime/security/advisories/new

Please do not open a public issue for it.

In scope: the skills' instructions and `cenk-overtime/skills/start/scripts/git-history.sh`. Example: a way that credentials, source code or private messages reach the case folder, the package or anyone else.

Fixes ship as a new version; CHANGELOG.md says what changed.
